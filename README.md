# X Trending Topics

A simple website that shows the 25 most talked-about topics on X (formerly Twitter) in the Philippines, drawn as a colorful bar chart.

## What is this?

Every day, millions of people post on X, and certain topics become popular, or "trending." This little website gathers the top 25 trending topics in the Philippines and shows them in one easy picture. It refreshes on its own twice a day, so you can quickly see what people are talking about without scrolling through anything.

## How it works

1. Twice a day, a small automated helper quietly checks the latest list of trending topics.
2. It writes down the top 25 topics and saves them.
3. When you open the website, it reads that saved list.
4. It then draws the topics as a bar chart, with the number one topic shown as the longest bar.
5. You see today's trends at a glance, along with a note of when they were last updated.
